# Баня «Весна» в Чайковском

[Сайт и форма бронирования](https://shushakovd83-jpg.github.io/bana/) · [Журнал администраторов](https://shushakovd83-jpg.github.io/bana/admin/)

GitHub Pages публикует сайт и интерфейс журнала из корня ветки `main`. Форма отправляет заявку напрямую по HTTPS на сервер Amvera. Гостю достаточно одного нажатия. Сервер сохраняет запись и файл Excel до подтверждения на экране. Для уведомления администратору гостю не нужен аккаунт в ВК.

До подключения домена Amvera гостевые заявки продолжают поступать в прежний журнал. Страница администратора на GitHub Pages включит вход после проверки нового сервера. Команда подключения убирает временный адрес из конфигурации. Рабочие записи прежнего журнала нужно сверить при переключении.

## Подключение Amvera

1. Создайте в Amvera приложение с постоянным диском и одной работающей репликой. В разделе «Репозиторий» подключите `shushakovd83-jpg/bana`, ветку `main`. Файлы `Dockerfile` и `amvera.yml` уже задают порт 3000 и каталог `/data`. [Инструкция Amvera по подключению GitHub](https://docs.amvera.ru/applications/git/webhooks.html)
2. В секретах приложения задайте `ADMIN_PASSWORD` — пароль владельца длиной от 16 символов. Для ещё двух администраторов можно задать отдельные пароли `STAFF_PASSWORD_1` и `STAFF_PASSWORD_2`. Они смогут просматривать и редактировать брони и скачивать Excel. Настройки ключа ВК доступны владельцу.
3. Включите публичный HTTPS-домен приложения. После запуска откройте его путь `/health`. Сервер возвращает `{"service":"vesna-bookings","ready":true}`.
4. На GitHub откройте [«Подключить Amvera к сайту»](https://github.com/shushakovd83-jpg/bana/actions/workflows/connect-amvera.yml). Выберите **Run workflow**, ветку `main` и вставьте публичный HTTPS-адрес приложения. Задание проверит сервер, доступ с Pages и закрытую выдачу Excel. После этого оно переключит сайт и журнал. Эту же проверку можно выполнить локально через `node scripts/connect-amvera.mjs https://ВАШ-ДОМЕН` и опубликовать полученный файл `api-config.json`.

## ВКонтакте и Excel

Включите сообщения сообщества nagore59. С профиля e.shushakov напишите «Начать» в [чат «Весны»](https://vk.me/nagore59). В закрытом журнале под паролем владельца введите ключ сообщества с правом на сообщения. После проверочного сообщения сервер сохранит ключ и отправит ожидающие уведомления. При ошибке отправки заявка останется в Excel. Повторные попытки используют прежний random_id.

Кнопка «Скачать Excel» работает на телефоне и компьютере. В таблице есть имя и телефон гостя, дата, время, тариф, сумма, статус и прежнее время при переносе. Сеанс журнала длится до восьми часов. После перезагрузки страницы или перезапуска сервера нужно снова войти.

Сервер проверяет напоминания раз в минуту. По подтверждённой брони он уведомляет администратора за сутки. Для напоминаний самому гостю задайте секреты `VK_GROUP_ID`, `VK_CALLBACK_SECRET` и `VK_CONFIRMATION`, укажите в настройках сообщества адрес `https://ВАШ-ДОМЕН/vk/callback` и включите событие `message_new`. После заявки гость переходит по персональной ссылке и отправляет сообщение сообществу.

## Хранение данных

Журнал, очередь уведомлений и актуальная книга Excel хранятся в SQLite на постоянном диске Amvera `/data/vesna.sqlite`. Для резервного копирования используйте снимки постоянного диска. Доступ к рабочей таблице защищён на сервере. В публичном репозитории находятся исходники, фотографии, файл автономной версии и пустой шаблон Excel.

## Проверка

`npm test` запускает проверки заявки, настоящего XLSX, повторных отправок, прав доступа, очереди ВК и сохранности данных после перезапуска. Для локального запуска задайте `DATA_DIR`, `ADMIN_PASSWORD` и `PAGES_ORIGIN` для локального интерфейса, затем выполните `npm start`. Автономный HTML собирается командой `node scripts/offline.mjs`.
