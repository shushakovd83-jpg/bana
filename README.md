# Баня «Весна»

[Открыть сайт бани «Весна»](https://vesna-banya-chaikovsky.almondmarmalade4.chatgpt.site/?view=public)

Сайт бани в Чайковском с публичной формой, закрытым журналом владельца по адресу /admin и выгрузкой Excel. Статические файлы лежат в dist, серверный код — в src. Страница формы требует работающего серверного API.

## Сборка
Установите Node.js 22 или новее. Выполните npm ci и npm run build. Готовый модуль Worker находится в dist/server/index.js.

## Размещение
Проект рассчитан на ChatGPT Sites с серверной авторизацией платформы. Привяжите закрытое хранилище R2 под именем BUCKET и задайте JOURNAL_OWNER_EMAIL как секрет окружения. Платформа должна удостоверять пользователя и устанавливать заголовки oai-authenticated-user-id и oai-authenticated-user-email сама. При самостоятельном размещении требуется заменить проверку личности или использовать доверенный шлюз, который удаляет переданные клиентом заголовки. GitHub Pages обслуживает только статические файлы.

## ВКонтакте
Для отправки сообщений нужны секреты VK_TOKEN, VK_ADMIN_PEER, VK_CALLBACK_SECRET, VK_CONFIRMATION и VK_GROUP_ID. Подключите Callback API сообщества к /vk/callback, версию 5.199 и событие message_new. Гость связывает диалог со своей заявкой через персональную ссылку. Для напоминаний зарегистрируйте периодический вызов обработчика scheduled на платформе Worker. Без этой настройки автономная доставка за сутки не работает. Ключи, рабочий журнал и контакты клиентов храните вне Git.
